Lembar Hasil Belajar
Integrasi AI (Gemini API Key Studio)

Key tersimpan aman di peramban lokal perangkat IFP (Local Storage) dan tidak dikirim ke server luar.

Mengenai Limit & Error:
• Error 503 (Unavailable): Server Google sedang padat global. Tunggu beberapa detik lalu coba kembali.
• Error 429 (Rate Limit): Kuota Free Tier habis. Buat API Key baru di Google AI Studio dengan memilih "Create API key in a new project".
Panduan Mendapatkan API Key (Gratis):
  1. Buka situs Google AI Studio.
  2. Login menggunakan akun Google / Akun Belajar Anda.
  3. Klik tombol biru "Create API key" di sebelah kiri.
  4. Pilih opsi Create API key in a new project (penting untuk reset kuota).
  5. Salin (Copy) kode yang muncul lalu tempel (Paste) di kolom input.
